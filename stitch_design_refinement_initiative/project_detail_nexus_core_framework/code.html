Nexus Core Framework

High-performance, asynchronous backend framework built in Rust.

info Project Overview

Designed for modern microservices architectures, Nexus Core provides a suite of zero-cost abstractions for handling concurrent network requests. By leveraging Rust's ownership model and the Tokio runtime, it guarantees memory safety while achieving throughput limits comparable to bare-metal implementations. It serves as the foundational spine for distributed systems requiring extreme reliability and low latency.

use nexus_core::{Server, Router, Response};

#[tokio::main]
async fn main() {
    let router = Router::new()
        .get("/api/status", |req| async {
            Response::ok("System Nominal")
        })
        .post("/api/data", handle_data_ingest);

    let addr = "0.0.0.0:8080";
    println!("Starting Nexus engine on {}", addr);

    Server::bind(addr)
        .serve(router)
        .await
        .expect("Server failed to start");
}
